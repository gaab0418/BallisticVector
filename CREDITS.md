# Créditos e licenças

Todo asset do Ballistic Vector tem origem e licença registradas aqui. Nada de
licença incerta entra no projeto.

## Fontes (`assets/fonts/`)

| Arquivo | Uso | Autoria | Licença |

| `VT323-Regular.ttf` | Texto, números e fórmulas | The VT323 Project Authors (Peter Hull) | SIL Open Font License 1.1 — `OFL-VT323.txt` |
| `Handjet-Variable.ttf` | Fallback (θ e setas) | The Handjet Project Authors (Rosetta Type) — github.com/rosettatype/Handjet | SIL Open Font License 1.1 — `OFL-Handjet.txt` |
| `Jersey10-Regular.ttf` | Títulos e logotipo | The Soft Type Project Authors — github.com/scfried/soft-type-jersey | SIL Open Font License 1.1 — `OFL-Jersey10.txt` |

Todas baixadas do repositório oficial do Google Fonts (github.com/google/fonts),
sem modificação. A OFL permite uso, cópia e redistribuição embutidas no jogo,
inclusive comercial, desde que a licença acompanhe as fontes.

## Sprites derivados

`assets/sprites/tank_hull.png` e `assets/sprites/tank_barrel.png` são recortes de
`tank_player.png` (o casco sem o cano, e o cano sozinho), gerados por
`tools/split_tank_sprite.py` para o cano girar com o ângulo. Mesma origem e
licença do sprite original.

## Arte procedural

Molduras de interface (`scripts/ui/ui_frame.gd`), ícones (`scripts/ui/ui_icon.gd`),
ícone de munição (`scripts/ammo_icon.gd`), céu, montanhas, terreno, régua,
trajetória, efeitos (`scenes/arena/`) e diagramas da ajuda foram desenhados em
código para este projeto, a partir da paleta de `scripts/ui/ui_tokens.gd`.
Não dependem de nenhum arquivo de imagem de terceiros.
